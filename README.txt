초루딩 퀴즈게임 실행 방법

1. 압축파일을 풉니다.
2. 폴더 안의 index.html을 더블클릭합니다.
3. 브라우저에서 퀴즈를 시작합니다.

중요:
- index.html, style.css, script.js, banner.png, profile.png를 같은 폴더에 두세요.
- 다른 사람에게 전달할 때는 압축파일 전체를 전달하세요.
- 인터넷 연결이 없으면 Google Fonts만 기본 글꼴로 대체될 수 있지만 게임은 실행됩니다.


9번 문제 채점:
흑초, 블릭, 하랑, 폭스, 액스, 노아, 머디, 토리, 토토, 리트,
베티, 도브, 온, 리버, 올베, 유오, 헤스 중 서로 다른 이름
3개 이상을 입력하면 정답으로 처리됩니다.
